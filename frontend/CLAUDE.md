# Frontend

React 19 + Vite + TypeScript, Tailwind 4, shadcn/ui (Base UI). Package manager is npm (not pnpm). Commands and testing rules are in the root `CLAUDE.md`.

@UI_GUIDELINES.md

## Conventions

- `src/components/ui/**` is generated by shadcn. Add components with `npx shadcn@latest add <component>`; do not hand-edit or write tests for them.
- Feature code lives in `src/components/<feature>/` (see `doc-wizard/`), with its hooks, types and config beside the components. Shared helpers go in `src/lib/`.
- Routing is hash-based via `src/lib/useHashRoute.ts`; there is no router library.
- Use the `@` alias for `src/` imports where it already prevails in the file; match the surrounding style.
- Use semantic color tokens and Lucide icons only (see the guidelines above).
- Design mobile-first. Camera and wake-lock features need HTTPS; the dev server is reachable from a phone and allows `.trycloudflare.com` tunnels.
- API calls go to relative `/api/...` paths (Vite proxies them in dev); mutating requests need the CSRF token flow used by the existing admin auth code.
